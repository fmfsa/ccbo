# QCBO — Quotient Causal Bayesian Optimization

Code, benchmark inputs and reproducible results. The manuscript is maintained in
Overleaf; `paper/` contains figures, table fragments, shared styles and
apply-ready manuscript corrections in `paper/revisions/`.

QCBO uses a supplied partition and cluster graph for intervention-set selection
and causal priors. QDCBO and QMCBO apply the construction to dynamic and
model-based causal Bayesian optimization. Package names retain the historical
`ccbo` spelling.

## Keep these files

- `ccbo/`: implementation, vendored CBO backend, benchmark data and tests.
- `scripts/`: experiment runners, external-stack fetchers, analysis and exports.
- `artifacts/traces/`: authoritative compressed raw traces, sidecars, hashes and
  provenance. Do not replace these with summaries alone.
- `artifacts/summaries/`: machine-readable aggregates used by table emitters.
- `envs/`, `pyproject.toml`, `uv.lock`: environment records and package configuration.
- `paper/figures/`, `paper/tables/`: current Overleaf result assets, including
  hand-tuned TikZ sources that are not regenerated by default.
- Tracked `results/*.json`: inputs to retained legacy analysis commands; these
  are historical results, not the current paper's authoritative evidence.

## Environment and tests

Use an existing environment or `python -m pip install -e .`.
[envs/README.md](envs/README.md) records the environments used on the experiment
server and the separate older MCBO stack. Preserve `.venv/` and package metadata
when cleaning a working checkout; they support the local installation.

```bash
.venv/bin/python -m pytest
# Additional numerical checks:
.venv/bin/python -m pytest -m slow
```

Tests requiring missing external stacks skip. Fetch pinned stacks with
`scripts/fetch_dcbo.sh`, `scripts/fetch_mcbo.sh`, `scripts/fetch_ceo.sh` when needed.

## Reproduce historical archive figures

```bash
bash scripts/reproduce_results.sh
# Or choose the environment explicitly:
PYTHON=/path/to/python bash scripts/reproduce_results.sh /path/to/extracted-traces
```

This verifies archive and per-file checksums, checks aggregates and protected-pair
invariance, and regenerates the historical archive figures and tables. It does
not regenerate the corrected dynamic results or the pending static/MCBO results.
For the audited dynamic assets, see
`artifacts/review-20260916/dynamic/generate_dynamic_assets.py` and the
corresponding audit data.
The QMCBO summary separates final-value, incumbent-trajectory and actual
decision/score equality, with required paired metadata and logs. The protocol
manifest records per-run settings and observation counts from the archives. It does
not build a manuscript or require LaTeX. The old `scripts/reproduce_paper.sh`
command remains an alias. Do not use regenerated historical assets to fill the
corrected manuscript’s pending results. See [paper/README.md](paper/README.md)
for the directly revised Overleaf source and its audited assets.

For new runs, see [scripts/README.md](scripts/README.md). Provenance is in
[artifacts/traces/MANIFEST.md](artifacts/traces/MANIFEST.md); the final corrected
engine record is [ENGINE_V3.md](artifacts/traces/ENGINE_V3.md).
See [KNOWN_ISSUES.md](KNOWN_ISSUES.md) for implementation limits.

## Historical reporting validation (2026-09-16)

The initial reporting-only revision preserved numerical behavior and archived
traces. Subsequent corrected experiment implementations in this branch do change
numerical behavior; their protocols and validation are recorded in
[EXPERIMENT_STATUS.md](EXPERIMENT_STATUS.md). The following diagnostic describes
the historical implementation, not the corrected experiment mode. Server checks
used the existing pinned MCBO and DCBO environments. QMCBO's singleton graph
construction is identical to the fine construction, but its learned-noise
SingleTaskGP differs from upstream MCBO's FixedNoiseGP. Numerical equivalence
to that upstream implementation is not claimed. See the manuscript patches and
`scripts/revision/probe_singleton_mcbo.py` for the diagnostic.
