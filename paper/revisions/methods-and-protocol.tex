\subsection*{Appendix B.1 --- replace scalar UCB/LCB description (M05)}

MCBO and QMCBO use mechanism-level optimism. For coordinate j of a nonintervened cluster C, the optimistic mechanism is

\[
\widetilde h_{C,j}(p,\eta)=m_{C,j}(p)+\beta\eta_{C,j}s_{C,j}(p),\qquad \eta_{C,j}\in[-1,1],
\]

before adding the residual disturbance. The mechanisms are composed in quotient topological order; intervened coordinates are clamped. The shared upstream acquisition is qSimpleRegret over the hallucinated network with 128 Sobol Monte Carlo samples. Each allowed target is considered in its stored order; a strict improvement replaces the current best target. The acquisition optimizer jointly searches intervention values and optimism coordinates. It uses q=1, 100d raw samples and 10d restarts, where d is the full acquisition dimension, including optimism coordinates. Initial-condition evaluation uses batch limit 10d and optimization uses batch limit 2; there is no additional posterior-mean start for MCBO. The box is [0,1]\textasciicircum{}d and optimism coordinates are transformed to [\ensuremath{-}1,1]. \ensuremath{\beta}=10 multiplies posterior standard deviation directly, not its square root. The coordinatewise confidence box for a multi-variable cluster is a relaxation of a joint ellipsoid, not a new calibrated joint-confidence guarantee. Multi-member residuals are sampled from fitted full-rank task-noise covariance plus global likelihood noise (Cholesky jitter 10\textsuperscript{-}\textsuperscript{9}); singleton residuals follow the environment noise distribution. This is distinct from a scalar reward GP's UCB/LCB.

Source: \nolinkurl{ccbo/qmcbo/qgp_network.py}, pinned MCBO \nolinkurl{mcbo_trial.py} and \nolinkurl{optimize_acqf.py} at 0d0650e. The runner's configured batch\_size=2 is used by the alternative NMCBO branch, not this MCBO acquisition path.

\subsection*{\S{}3.2 / Appendix B.3 --- joint mechanisms and finite implementation evidence (M06/M10)}

Multi-variable QMCBO clusters use KroneckerMultiTaskGP with a full-rank MultitaskGaussianLikelihood; singleton clusters use SingleTaskGP with outcome standardization. A cluster mechanism is fitted only on rows where none of its members was intervened on. Inputs comprise all fine variables in its parent clusters, in sorted node-index order. The range normalizer is fitted to all accumulated parent observations before applying the mechanism's intervention mask; the same ranges are used at prediction, with a zero-range guard. Roots receive a constant zero feature. Hyperparameters maximize exact marginal likelihood. Multi-member mechanisms receive no explicit outcome transform. The pinned BoTorch 0.7.2 defaults use a Matérn-5/2 ARD input covariance and a full-rank task covariance; the scalar model adds an output-scale kernel. These fitted GP and confidence approximations are distinct from the exact quotient factorization statement.

DCBO/QDCBO and MCBO/QMCBO use pinned upstream implementations with local adapters. Both dynamic methods receive the same corrections: regress child values at the child's time on parents at their own times, and test interventions/seeds with \texttt{\detokenize{is not None}}, preserving zero-valued interventions. QDCBO multi-member mechanisms use GPy GPCoregionalizedRegression with RBF\ensuremath{\times}ICM covariance and per-output Gaussian likelihoods; singleton mechanisms delegate to the scalar upstream fit. The MCBO adapter sets NumPy/torch seeds, neutralizes upstream torch.seed(), uses float64, and records decisions; QMCBO substitutes the joint cluster network and lifts targets.

The singleton quotient is a structural reduction, not a claim of numerical identity with pinned MCBO. Upstream MCBO uses FixedNoiseGP with supplied environmental noise variances, while this QMCBO implementation learns singleton likelihood noise. A matched 40-row synthetic probe (data seed 7, fit seed 123) found a maximum posterior-mean difference of 0.0356192 and a maximum variance difference of 0.00593804 across the three nodes. Fresh external-stack checks passed 11 MCBO tests and 15 DCBO tests with zero skips; these do not establish a universal executable-identity theorem. The dynamic tests include short finest-partition comparisons under both stock and corrected modes; the MCBO singleton test checks model structure rather than full baseline trace identity.

\subsection*{Appendix B.2 --- identification, estimator support and exceptions (M07)}

The Ananke 0.5.0 OneLineID gate runs on the supplied fine or cluster ADMG. For identified queries the numerical implementation tries backdoor, frontdoor and g-computation in that order. Formal identification, numerical estimator support and execution success are distinct. Nonidentified or unsupported queries use constant observational Y mean and sample variance (pandas variance, ddof=1). Caught gate construction/identification errors (ValueError, TypeError, KeyError, AssertionError) warn, record gate\_status=error and fail closed to that fallback. Missing Ananke raises ImportError. Estimator fitting/execution exceptions are not covered by a general fallback handler: they propagate; they must not be described as mathematical nonidentification. Symbolic-functional string extraction is best-effort and does not overturn a successful ID result. The gate's not\_run state denotes an invalid/absent target or intervention in the supplied graph.

Conditional regressions use GPy 1.13.2 GPRegression with ARD RBF covariance, fitted by \nolinkurl{optimize(messages=False)} with package-default initialization and optimizer, and likelihood variance constrained to [10\textsuperscript{-}\textsuperscript{6},10]. Let outcome predictions on mixture rows i be \ensuremath{\mu}\_i, latent variance s\_i\textsuperscript{2} and fitted constant outcome likelihood variance \ensuremath{\sigma}\_Y\textsuperscript{2}, with normalized weights w\_i. Every supported branch returns

\[
\bar\mu=\sum_iw_i\mu_i,\quad B=\sum_iw_i(\mu_i-\bar\mu)^2,\quad E=\sum_iw_is_i^2,\qquad v_{\rm predictive}=\sigma_Y^2+B+E.
\]

The archived policy is predictive. The optional total policy is \ensuremath{\sigma}\_Y\textsuperscript{2}+B; the diagnostic epistemic policy is E+B/n\_obs. These are priors supplied to the arm surrogate, not that surrogate's posterior uncertainty. B/n\_obs is a reported diagnostic term, not a complete error bound on the effect estimate. Intermediate-variable plug-in laws use fitted GP means and likelihood variance, excluding intermediate GP epistemic variance.

Backdoor uses empirical adjustment rows z\_i with weights 1/n: evaluate the outcome GP at (a,z\_i). Frontdoor implements

\[
\widehat E[Y\mid do(S=a)]=\int \widehat p(m\mid a)\Big\{n^{-1}\sum_{r=1}^n\widehat E[Y\mid m,S=s_r]\Big\}\,dm.
\]

Vector mediators are generated by the chain-rule conditional product in their canonical order. Up to two mediators use a 20-node Gauss--Hermite product rule per mediator; above two, 400 seeded common-random-number Gaussian draws replace quadrature. Cross each mediator node with all observed S rows and use weights w\_node/n in the common moment formula. This integrates nonlinear responses rather than substituting mediator means.

G-computation: replicate every observational row four times; clamp intervention coordinates to a; traverse the supported plan in topological order; generate each propagated variable as its fitted conditional mean plus its fitted likelihood standard deviation times Z; include earlier variables of its cluster as conditioning variables via the chain rule. Retain unpropagated base values from the observational rows. Evaluate the final outcome GP on those rows and apply uniform weights 1/(4n) in the same moment formula. Z is drawn once with estimator seed 0 and reused across intervention values. Root/latent-expansion nodes without a supported observed conditional are not generated as new latent data. This procedure supports the selected plans, not every identifiable functional.

\subsection*{Appendix C --- decision rounds, domains and model-based scores (M09/M11/M12)}

The controlled suite uses 30 paired seeds, three initial points per arm and unit cost per intervened variable. T counts post-initialization decisions: 50 for ParallelParent/FrontDoor and 60 for MediatedChain. CBO/QCBO may acquire observations or intervene; observations cost zero intervention units and leave the incumbent unchanged. The observation probability is the observed convex-hull/domain-volume ratio divided by n\_obs/effective\_cap, clipped to [0,1]; a fresh optimizer phase first observes if budget remains. Initialization and split initialization are charged separately. BO/BO-S use intervention-only policies. Equal rounds do not imply equal intervention counts or costs.

An audit of all 90 arm-family decision sidecars gives: in each of the ten Toy and CompleteGraph seeds, CBO/QCBO execute 37 interventions and three observation rounds, versus BO's 40 interventions. Coral CBO/QCBO execute 39 interventions and one observation round in each of ten seeds. Complete condition/method min/max schedules for 1320 controlled units are in the JSON; do not extrapolate one schedule to every benchmark.

The controlled SCMs use independent standard-Gaussian disturbances:

\[
\begin{aligned}
\text{ParallelParent: }\quad U&=0.4\epsilon_0,\quad X_1=U+0.3\epsilon_1,\quad X_2=U+0.3\epsilon_2,\\
Y&=(X_1-2)^2+(X_2+2)^2+0.1\epsilon_Y.\\[2pt]
\text{FrontDoor: }\quad U&=0.4\epsilon_0,\quad X_1=U+0.3\epsilon_1,\quad M=2X_1+0.2\epsilon_2,\\
Y&=2\{1-\exp[-(M-1)^2/(2\cdot0.3^2)]\}+U+0.1\epsilon_Y.\\[2pt]
\text{MediatedChain: }\quad X_1&=0.5\epsilon_1,\quad X_2=2X_1+0.2\epsilon_2,\\
Y&=(X_2-4)^2+0.1\epsilon_Y.
\end{aligned}
\]

ParallelParent and FrontDoor intervention domains are [\ensuremath{-}3,3] for both manipulable variables. MediatedChain uses D(X\textsubscript{1})=[\ensuremath{-}3,3] and D(X\textsubscript{2})=[\ensuremath{-}2,2]. Natural responses are not clipped to intervention domains; controlled learning/scoring use population expectations.

The model-based suite uses 20 paired seeds, 100 decisions and maximization. ToyGraph uses noise\_scale=0; its ZeroDist produces exactly-zero draws but advertises variance 10\textsuperscript{-}\textsuperscript{6} for GP stability. PSAGraph remains stochastic: age\ensuremath{\sim}Uniform[55,75], bmi\ensuremath{\sim}Normal(27\ensuremath{-}0.01age,0.7\textsuperscript{2}), and PSA has conditional standard deviation 0.4. Aspirin, Statin and Cancer are deterministic sigmoid functions of their parents in the actual simulator; declared auxiliary noise metadata of standard deviation 0.001 for those variables is not additional simulator noise. Reward is \ensuremath{-}PSA. Only Aspirin/Statin can be intervened on, individually or jointly for MCBO and as one whole cluster for QMCBO. Their normalized intervention domains are [0,1]. The score routine averages 100,000 simulator draws per candidate and reports the running maximum including initialization. These score draws are separate from the one network observation per candidate used for learning and the 128 acquisition samples. In the PSA panel, larger reward means lower PSA.

\subsection*{Supplementary CEO paragraph (M18)}

CEO at upstream revision 35dd277 is supplementary: learning and graph-posterior updates use stochastic samples from the true latent SCM, while scoring uses the controlled suite's population oracle. It receives the first 100 shared observations, three initial points for each nonempty manipulable subset, seeds 0--29, and T=50 or 60 with an extra initialization row in the upstream T+1 convention. Its graph pool contains only observable DAGs, with the asserted graph first and uniform weights. ParallelParent's distinct pool is A0/A1/A2 (one-third each); FrontDoor and MediatedChain have singleton pools B0/C0. A3 is explicitly aliased to A0, and B1 to B0: this machinery cannot represent bidirected perturbations. The recorded baseline-observable posterior is not posterior mass on the true latent ADMG. The adapter sets nominal num\_anchor\_points=35; the upstream acquisition evaluates 35 sampled scalar candidates but only floor(sqrt(35))=5 two-variable candidates, then selects the largest acquisition. The effective anchor seed is (run seed+1)\ensuremath{\times}(time index+1)\ensuremath{\times}iteration, NumPy/Python seed=run seed and a stateful RandomState(run seed); the objective seam check uses seed 10000+run seed. The shared CEO compatibility adapter also preserves multi-character names, caps interventional-grid resolution (15 per dimension for two variables), restores the GPy inverse-Gamma moment constructor, uses exact array-byte cache keys, stubs an absent plotting import, and removes an unused emission-GP deepcopy. Initialization and sequential costs are included. A shared scoring objective does not make the learning noise or action families identical, so this comparison does not isolate optimizer quality under a matched observation interface.


The pinned CEO conditional mechanism GP is GPy GPRegression with a non-ARD RBF; initial lengthscale, kernel variance and likelihood variance are all 1. Inverse-Gamma priors are specified by (mean, variance): lengthscale (1,1), kernel variance (4,0.5), likelihood variance (3,1). Likelihood noise is learned. Fits use ten robust restarts and seed 0. Roots use Gaussian MyKDE (the historical sklearn KernelDensity default bandwidth 1); each mean/variance prediction uses separate sets of 500 samples. Arm surrogates use CausalRBF with lengthscale=variance=1, initial learned likelihood variance 10\textsuperscript{-}\textsuperscript{5} and inverse-Gamma mean/variance pairs (1,1), (1,1), (1,0.2) for lengthscale, kernel variance and likelihood respectively. Each arm fit runs five restarts under the run seed, restoring the surrounding NumPy RNG state. These are GPy 1.13.2 optimizers with no adapter tolerance override.

CEO uses causal entropy search divided by cost for fitted arms (manual causal EI before a fitted arm model). It forms local optimum distributions from 200 posterior function draws; multivariate local-minimum searches use 100 uniform points with seed 0, while scalar searches use the stored 35-point grid. The global optimum mixture uses 1000 samples with stratified arm resampling. Fantasy observations are integrated by five-node Gauss--Hermite quadrature. Entropy estimation uses statsmodels KDEUnivariate.fit with its historical-version defaults and bandwidth 0.5 if fitting fails. When normalized posterior mass on graph index 0 exceeds 0.90, the code uses its optimization-only entropy branch; this explains the significance of asserted-graph-first ordering. The adapter's separate stored joint grid has 15\ensuremath{\times}15 points, distinct from the five actual acquisition candidates and the 100 local-minimum points. Online=False, concat=False, use\_mc=False, do\_cdcbo=False and unit costs are the pinned constructor defaults used here.
